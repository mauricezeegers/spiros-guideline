Public home of the SPIROS 2026 guideline. GitHub Pages serves the site at https://mauricezeegers.github.io/spiros-guideline/. www.spiros-guideline.org redirects to the README on GitHub.

## Location and git
* Working tree: ~/Library/CloudStorage/GoogleDrive-zeegersmaurice@gmail.com/My Drive/Documenten/SPIROS/spiros-guideline
* `.git` points to the Extreme SSD; it must be mounted. You commit and push yourself (`git pull --rebase`, clear commit message, `git push`).
* This repo is PUBLIC: never add names, e-mail addresses or raw feedback from respondents, API keys or other private data.

## Files
* `index.html`: interactive checklist (ticks and notes stay in the visitor's browser, localStorage key `spiros-2026-checklist-v1`).
* `feedback.html`: feedback form, posts to Formspree `https://formspree.io/f/xqpakpyr`. Keep the text saying that a filled-in name is added to the acknowledgements and that this is optional.
* Both pages contain the same item data in `<script id="items-data" type="application/json">`. Regenerate it from the E&E paper with `../spiros-data/code/site/build_items_from_ee.py`; never edit item text by hand in only one page.
* `README.md`: the block between `<!-- FEEDBACK-FIGURES:START ... -->` and `<!-- FEEDBACK-FIGURES:END -->` and the acknowledgements list are generated by `../spiros-data/feedback-analysis/update_public.py`. Do not edit those parts by hand.
* `figures/`: radar charts written by `update_public.py`.
* Untracked on purpose (`.gitignore`): `Claude outputs/`, `SPIROS_2026_Departmental_Seminar.html`, `SPIROS_2026_Departmental_Seminar.pptx`.
